# 🛒 GreenCart – Online Grocery Shopping

**GreenCart** is a modern, responsive frontend web application built with **React.js** for a seamless online grocery shopping experience.

## 🚀 Features
*   **Product Catalog:** Browse fresh groceries categorized dynamically.
*   **Search & Filter:** Find essential grocery items instantly.
*   **Shopping Cart:** Add, remove, and update item quantities with live total updates.
*   **Responsive Layout:** Fully optimized for mobile, tablet, and desktop screens.
